# MazeLab

面向数据结构与算法学习者的迷宫生成、求解与逐步可视化工具。

## 1. 项目背景与目标

**面向谁：** 正在学习栈、队列、优先队列、并查集和图遍历的学生/自学者；需要准备演示和练习题的教师/助教。

**解决什么问题：** 常见迷宫示例只给最终图案，不展示算法过程；随机结果难以复现；缺少自动验证，难以确认迷宫连通性、无环性、路径合法性、BFS 最短路性质。

**已完成功能：** 项目骨架。

**计划功能：**

- [ ] 迷宫核心数据结构（单元格、墙位掩码）
- [ ] DFS 回溯生成（一键 + 逐步）
- [ ] 随机 Prim 生成（一键 + 逐步）
- [ ] Kruskal + 并查集生成
- [ ] BFS 求解（一键 + 逐步）
- [ ] A* 求解（一键 + 逐步）
- [ ] 命令行工具 generate / solve / validate
- [ ] JSON 导入导出
- [ ] 自动测试：连通性、无环性、路径合法性、seed 复现
- [ ] 本地 Web 可视化

## 2. 课程知识与核心设计

| 算法           | 数据结构              | 用途               |
| -------------- | --------------------- | ------------------ |
| DFS 回溯生成   | 栈                    | 生成路径较长的迷宫 |
| 随机 Prim 生成 | 优先队列 / frontier   | 分支更均匀         |
| Kruskal 生成   | 并查集                | 随机边合并         |
| BFS 求解       | 队列                  | 最短路             |
| A* 求解        | 优先队列 + 曼哈顿距离 | 启发式搜索         |

**核心表示：** 每个单元格用四面墙位掩码（N=1, E=2, S=4, W=8），打通相邻两格时同时清除双方对应墙。

**逐步可视化：** 生成器和求解器都以 Python 生成器 yield StepSnapshot，每个快照包含当前迷宫、栈/队列/堆内容、已访问集合、动作描述。

## 5. 测试与结果

已有冒烟测试 tests/test_smoke.py，验证包可导入、Maze 能初始化、StepSnapshot 能创建。

计划覆盖：连通性、无环性、通道边数 = 格数 − 1、路径合法、BFS 与 A* 路径长度一致、相同 seed 复现、损坏 JSON、越界起终点、无解迷宫、1×1 与 1×N 边界。

## 6. 局限与改进

- 当前仅支持完美迷宫生成，尚未支持带环路或障碍的非完美迷宫；
- 逐步快照每帧保存完整迷宫，大尺寸下内存与传输开销待优化；
- Web 可视化尚未实现；
- 尚未做算法性能对比实验。
